# RoomFit furniture packs

Converted CC0 assets from [Kenney Furniture Kit 2.0](https://kenney.nl/assets/furniture-kit).
Author: Kenney. Source licence: Creative Commons Zero (CC0). See LICENSE-Kenney.txt.

These are illustrative, low-poly furniture models, not product measurements or scans.
120 selected models are grouped into five packs. Architectural wall, floor, doorway,
stair and panel pieces are excluded. Original source meshes and colours are retained;
meshes are converted to Y-up, metre-based USDZ, centred horizontally and placed on the floor.
No Blender or AI generation is used in conversion.

Pack JSON holds asset metadata, base64 USDZ and JPEG previews. manifest.json lists
byte sizes and SHA-256 hashes. This repository contains public CC0 assets and pack
metadata only; it contains no private app source, scans, user photos or credentials.
